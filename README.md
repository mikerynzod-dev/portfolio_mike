# MRDV Portfolio (React + Vite + Tailwind + Framer Motion)

    npm install     # install dependencies
    npm run dev     # dev server
    npm run build   # production build (dist/)

Contact form: copy .env.example to .env and set VITE_FORM_ENDPOINT (for example a Formspree endpoint). Until it is set, the form says it is not connected.
Edit projects in src/data/projects.js and education details in src/components/Education.jsx.
